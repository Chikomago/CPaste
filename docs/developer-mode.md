# 诊断模式

在「设置 → 诊断」开启，默认关闭。开启后记录时间、应用版本与开发／正式构建、系统与架构、CPU 线程数，以及 macOS 系统版本、机型和内存；Windows 记录系统版本及处理器信息。

操作日志包含调用名称、成功／失败、耗时、面板呼出／收起、采集类型与图片字节数。不开启时不记录，不上传。不会写入剪贴板正文、图片像素、文件路径、规则源码、用户名或设备序列号。

日志通过有界队列在后台写入。单文件约 5 MB，保留当前文件和 3 份轮转文件，最多约 20 MB；队列满时丢弃日志，避免阻塞操作。关闭开关停止新增日志，已有日志保留，可使用「导出日志」保存为 JSON Lines。

macOS 日志目录：`~/Library/Logs/app.cpaste.desktop/developer/`；其他系统使用 Tauri 的应用日志目录。重现问题后导出日志；导出只读取日志，不包含历史数据库或资源文件。
