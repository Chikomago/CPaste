## CPaste 2.1.0

1. 新增三种面板布局：侧栏导航、横向浏览、分列浏览，可在「设置 → 界面」中切换。
2. 面板尺寸与位置随布局、详情展开状态自动计算并适配屏幕，边缘呼出时不再超出可用区域。
3. 新增「打开详情 / 收起详情 / 默认打开详情」设置与对应快捷键。
4. 「快捷处理」规则改为面板内自建列表，弹出位置自适应，样式与主面板统一。
5. 更新 README 界面预览：补齐三种布局对照图与设置界面截图。
6. 修复若干显示问题，优化窗口几何计算与滚动表现。

下载：macOS 按芯片选择 aarch64（Apple Silicon）或 x64（Intel）安装包；Windows 选择 x64 `.exe` 安装包，或免安装的绿色版 zip。

macOS 安装包采用临时签名，未经过 Apple 公证，安装时会遇到信任问题；Windows 安装包尚未使用商业代码签名证书。
