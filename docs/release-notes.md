CPaste 0.1.1：后台任务、图片粘贴与 macOS 崩溃修复。

- 修复 macOS 双击粘贴后进程退出：原生按键发送回到主线程，避免系统键盘布局接口断言。
- 修复大图处理、图片粘贴和焦点等待阻塞界面的问题，macOS 直接复用原始 PNG。
- 记录查询、编辑删除、设置清理、应用扫描、文件信息和备份恢复移至后台。
- 后台任务限制并发，关键写操作串行执行，剪贴板操作使用独立队列。
- 调整“关于”布局和更新检查行，移除多余关闭按钮和提示，总条数与条目正文对齐。


下载：macOS 按芯片选择 arm64/aarch64 或 x64 安装包；Windows 选择 x64 `.exe`。
版本仍为 0.1.1，已安装相同版本的用户需手动下载安装。
macOS 安装包采用临时签名，未经过 Apple 公证；Windows 安装包尚未使用商业代码签名证书。
