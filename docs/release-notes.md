## CPaste 1.0.1

1. 修复 Windows 主面板与设置窗口的圆角及白屏问题。
2. 修复 Windows 重复生成托盘图标、点击面板外不关闭的问题。
3. 新增面板拖动：macOS 与 Windows 均可按住空白处移动面板。
4. 优化快捷键提示：Windows 采用统一键帽符号，紧凑不溢出。
5. 优化独立预览面板：去除多余框线与背景色，按空格呼出时不再误关主面板。
6. 悬停预览改为跟随鼠标：光标移开条目后自动关闭。
7. 修复面板滚动偶发失效、平铺滑块卡顿等交互问题。
8. 其他性能及细节优化。

下载：macOS 按芯片选择 aarch64（Apple Silicon）或 x64（Intel）安装包；Windows 选择 x64 `.exe` 安装包，或免安装的绿色版 zip。

升级时会自动迁移图片资源，并保留迁移前备份。macOS 安装包采用临时签名，未经过 Apple 公证，安装时会遇到信任问题；Windows 安装包尚未使用商业代码签名证书。
