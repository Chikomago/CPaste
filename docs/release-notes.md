CPaste 首个公开版本：Windows 和 macOS 本机剪贴板管理。

- 支持文本、富文本、图片、文件记录，搜索、编辑、置顶和收藏。
- 支持中文分词、词典下载与自定义词典，保留原输入位置粘贴。
- 支持多种面板布局、中英文界面、主题和快捷键设置。
- 支持来源应用黑名单、敏感内容遮盖、存储清理、备份与恢复。
- 新增“关于”、自动检测更新和签名验证的在线更新。

下载：macOS 按芯片选择 arm64/aarch64 或 x64 安装包；Windows 选择 x64 `.exe`。
macOS 安装包采用临时签名，未经过 Apple 公证；Windows 安装包尚未使用商业代码签名证书。
